# K媽｜送給小時候的自己

內在小孩小測驗落地頁（單一 HTML 檔，圖片內嵌，不需要任何後端或外部資源）。

- 頁面檔案：`index.html`
- 測驗形式：四選一（小熊 / 夜燈 / 卡片 / 鑰匙），選完顯示完整解析與水晶推薦
- 導流：森靈水晶商店（`omnicrystal.store`），折扣碼 `Karen`

## 發布方式

GitHub Pages：Settings → Pages → Source 選 `Deploy from a branch`，
branch 選 `main`、資料夾選 `/ (root)`，存檔後 `index.html` 會成為網站首頁。

## 備註

整頁約 2.8 MB，其中裝飾用 PNG 佔約 1.6 MB。若日後想加快手機載入速度，
可將該張圖轉為壓縮後的 JPEG/WebP。
